# RU Basement Open
A tournament management system designed for darts and other indoor sports.

## Features
- **Architecture:** 3-tier design (UI, Logic, Data).
- **Interface:** Python TUI (Text-based User Interface).
- **Functionality:** Manage clubs, teams, players, and match schedules.
- **Scoring:** Supports Darts scoring (501, 301, Cricket) and Quality Points (QP) statistics.

## Tech Stack
- Python
- CSV/Text files for data storage
